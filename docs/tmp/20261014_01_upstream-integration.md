# upstream main の統合

- 対応 Issue: https://github.com/yukihane/yomi/issues/18
- 基点: 本リポジトリ main `03e376f`
- 統合対象: upstream main `00b4a47`（2026-10-14 に先端一致を再確認）
- PR ブランチ: `merge/upstream-main`

upstream の履歴を親に持つマージコミットで統合する。認証・OAuth・DOM 除外・キャッシュ分離と保存世代・負荷制限は本リポジトリの実装を維持する。旧キャッシュ API を復活させない。

翻訳提案、自動翻訳、ページ遷移、SPA の body 差し替え、アカウント表示、既定モデル、依存更新、knip、ライセンスを取り込む。サイト設定は保護した local 保存と background の直列更新に変更し、自動翻訳の許可は拡張画面からだけ変更できる。継続翻訳は同一オリジンに限定し、文書 ID を確認する。

別オリジン・異なるスキーム／ポートへの継続を拒否するテストを先に追加し、変更前に2件失敗することを確認した。実装後の検証結果は後続コミットで記録する。

既存の認証競合、サイト別の送信禁止、文脈送信制御、実アカウント・実モデル・配布リリースの検証は完了扱いにしない。
