# 最新 main を基点にした Firefox 対応

## 基点と方針

- 作業ブランチ: `feature/firefox-current`
- 基点: `origin/main` の `7beebd4`
- 旧 `feature/firefox` との共通祖先: `7a6ff1a`
- 旧ブランチに含まれていない main のコミット: 133 件

旧ブランチをマージせず、現行コードへブラウザー差分を移植した。main の翻訳要求形式、文書・送信元検証、要求上限、認証、キャッシュの停止・消去処理は保持した。旧ブランチにだけある過去の調査レポートは移植していない。

## 互換性の判断

- Firefox は153以降を対象にする。文書 ID は153から利用できる。古い140対応を残すために文書検証を省くことはしない。
- Firefox には `documentLifecycle` がなく、実機では `getFrame()` の `errorOccurred` も省略される。Firefox 用スキーマでのみ省略を許可し、現在のトップフレームの文書 ID とオリジンは照合する。
- Firefox は `storage.local.setAccessLevel()` を提供しないため、local 項目を拡張オリジンの IndexedDB に分離する。読み出しと変更通知は既存の `defineValidatedItem` を通して検証する。セッションストレージは既定の拡張専用アクセスを使う。
- 接続維持は content script からの ping に共通化する。ping は翻訳要求を増やさず、未送信15秒・要求120秒の期限を延ばさない。
- CI は Chrome と Firefox 153/156、リリースは両ブラウザーの zip を作成する。`uses:` は変更していない。

参考: [MessageSender の互換性](https://github.com/mdn/browser-compat-data/blob/main/webextensions/api/runtime.json)、[storage の互換性](https://github.com/mdn/browser-compat-data/blob/main/webextensions/api/storage.json)、[session の公開範囲](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/storage/session)。

## 検証結果

- `pnpm format` / `pnpm lint` / `pnpm typecheck` / `pnpm knip`: 成功。
- ユニットテスト: 38ファイル、397件成功（2026-10-15 再検証）。
- Chrome E2E: 15ファイル、78件成功、2件は既存の条件でスキップ。
- Firefox 153.0 / 156.0.1: manifest の検証を含む各12件がすべて成功（2026-10-15、旧コピーの整理を含む最終ビルド）。
- 両ブラウザーのビルドと配布 zip 作成: 成功。Firefox のソース zip から `tmp/` と `docs/tmp/` を除外した。

Firefox E2E は設定保存と設定共有、ショートカット設定、ページ・選択翻訳、動的な本文、原文切り替え、キャッシュ再利用、35秒の待機、停止・再試行、提案、自動翻訳、リンク先の継続翻訳、SPA、リロード時の解除、認証隔離、要求上限、キャッシュ無効化、サインアウトを確認した。外部 API はモックであり、実アカウントの OAuth サインインや Mozilla の署名審査は実施していない。

初回の Chrome E2E 全体実行では提案を閉じた直後の遷移テストが1件失敗した。単独の11件と、その後の全体78件は成功した。今回そのテストや Chrome 側の提案処理は変更していない。

## 保存移行の完了

2026-10-15 にユーザーから旧保存先の整理の承認を受け、IndexedDB の移行トランザクションがコミットされた後だけ、旧 `storage.local` の対象5項目を削除する処理を実装した。対象外の項目は保持する。

ユニットテストでは、対象データの保存と旧コピーの削除、対象外データの保持、移行失敗時の旧データ保持、削除失敗後の新旧データ保持、再試行時にサインアウト済みの新保存値を旧値で上書きしないことを確認した。削除失敗は初期化失敗として通知され、拡張機能の再読み込みで再試行できる。

`origin/main` は引き続き `7beebd4` であり、本ブランチの祖先であることを再確認した。未完了の実装事項はない。作業開始時から存在する未追跡の `tmp/` は変更していない。
