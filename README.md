# Yomi

![Yomi](docs/hero.png)

ChatGPT サブスクリプション（[Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source)）で Web ページを翻訳する Chrome・Firefox 拡張。

## 機能

- **ページ全体の翻訳**: スクロールやページの変化に合わせて、見えている部分から順に訳す。
- **翻訳の提案と自動翻訳**: 翻訳先と違う言語のページを開くと翻訳するか尋ねる。サイトごとに「常に翻訳」を登録すると、開いただけで訳す。翻訳中のタブでリンクをたどると、移った先のページも続けて訳す。
- **原文表示**: 訳文にホバーすると原文を表示する。ページ全体の原文 / 訳文も切り替えられる。
- **選択テキストの翻訳**: 選択したテキストをその場で訳す。
- **キャッシュ**: 明示的に保存を有効にした場合、同じ条件の訳文を7日間再利用する。

ショートカット: `Alt+T` 翻訳 / 停止（選択中は選択範囲を翻訳）、`Alt+O` 原文 / 訳文の切り替え

## 翻訳の提案とサイト設定

翻訳先と異なる言語のページでは、サインイン中に翻訳を提案する。提案を表示しただけでは翻訳 API に本文を送信しない。「翻訳する」を押すと送信を開始する。提案を閉じたタブではページを移っても提案を表示せず、リロードで再び表示する。

ポップアップまたは設定画面で「常に翻訳するサイト」に登録すると、そのサイトを開いた際に自動で本文を送信して翻訳する。ページ上の「自動翻訳を設定」は設定画面を開く。「提案しないサイト・言語」は提案の表示だけを抑制し、手動・自動・継続翻訳による送信を禁止しない。

翻訳中に同一オリジン（スキーム・ホスト・ポートが同じ）のページへリンク・フォーム送信・戻る／進むで移動すると、翻訳を継続する。別オリジン、アドレスバー、ブックマーク、リロードでは引き継がず、移動先の提案・自動翻訳設定に従う。停止・原文表示・キャッシュ消去・サインアウトでは継続状態も解除する。

サイト設定はこのブラウザープロファイル内だけに保存し、同じプロファイルのタブ・ウィンドウ間で共有する。別の端末には同期しない。モデル・言語・表示設定は従来どおり同期する。

## データの送信と保存

翻訳を実行すると、対象の文章を OpenAI の API（`api.openai.com`）へ送信する。ページ全体の翻訳では画面外の文章も対象になり、翻訳を停止するまで追加・変更された文章も処理する。文脈としてページタイトルの先頭200文字と説明文の先頭300文字も送信する。選択翻訳では選択した文章の先頭8,000文字までを送信する。

ページ本文などに個人情報や機密情報があれば、それも送信対象になり得る。現在はサイト別の翻訳禁止設定や、タイトル・説明文だけを送信しない設定はない。外部へ送信できない情報を含むページでは翻訳を実行しないこと。API には `store: false` を指定しているが、送信先での一切の保持を防ぐ保証ではない。

ページ翻訳の訳文の保存は既定で無効。設定で有効にした場合だけ、端末内に最大50,000件・書き込みから7日間保存する。読み取りでは期限を延長しない。期限後は返さず、次回起動・利用時に削除する。訳文は暗号化していない。手動消去、保存無効化、サインアウト、アカウント変更時に進行中の翻訳を中断して消去し、遅延応答の再保存を拒否する。消去に失敗した場合はキャッシュを停止し、設定画面から再試行できる。選択翻訳とシークレットモードでは永続キャッシュを参照・保存しない。更新時は旧キャッシュを破棄するため再翻訳が必要になる。

認証では `auth.openai.com` と通信し、認証トークンとメールアドレスを端末内に保存する。モデル・言語・表示設定は ブラウザーの同期用ストレージに保存する。端末やブラウザープロファイルを共有する場合は、これらの保存内容にも注意すること。

## 導入

Chrome 140 以降、Firefox 153 以降に対応する。

### Chrome

1. [Releases](https://github.com/shun-shobon/yomi/releases) から最新の `*-chrome.zip` をダウンロードして展開する。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」から展開したフォルダを選ぶ。
4. 拡張のポップアップから「ChatGPT でサインイン」を押し、開いたタブでアクセスを許可する。

更新するときは新しい zip を同じフォルダに展開し直し、`chrome://extensions` で再読み込みする。

### Firefox

1. Firefox 用の `*-firefox.zip` を展開する（手元でビルドする場合は `pnpm build:firefox`）。
2. `about:debugging#/runtime/this-firefox` を開く。
3. 「一時的なアドオンを読み込む」から展開先の `manifest.json`（ビルド時は `.output/firefox-mv3/manifest.json`）を選ぶ。
4. 拡張のポップアップから「ChatGPT でサインイン」を押す。

未署名の開発版は Firefox の再起動で外れる。通常のアドオンとして配布するには Mozilla の署名が必要。設定画面の「ショートカットを変更」から Firefox 標準の設定を開ける。

Firefox では認証情報・サイト設定・キャッシュ設定を拡張専用の IndexedDB に保存する。認証途中の状態とタブの状態は、ページ側から参照できないセッションストレージに保存する。Firefox 153 未満は文書 ID を使う検証に対応できないため対象外。

### 翻訳の上限

選択文とページ内の1セグメントは8,000文字まで。ページの1要求は25セグメント・合計20,000文字、タイトルは1,024文字、説明文は2,048文字まで。超過は切り捨てずエラーを表示する。翻訳結果は64,000文字、APIの応答全体は2 MiBで受信を中断する。

翻訳接続は1文書4件・拡張全体16件まで。上限時は待機キューに積まず、完了後の再試行を案内する。未送信接続は15秒、翻訳要求は120秒で終了する。設定・使用量・ショートカット画面を開くAPIは、連打を防ぐため全体で1秒に1回に制限する。
