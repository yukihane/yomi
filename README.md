# Yomi

![Yomi](docs/hero.png)

ChatGPT サブスクリプション（[Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source)）で Web ページを翻訳する Chrome 拡張。

## 機能

- **ページ全体の翻訳**: スクロールやページの変化に合わせて、見えている部分から順に訳す。
- **原文表示**: 訳文にホバーすると原文を表示する。ページ全体の原文 / 訳文も切り替えられる。
- **選択テキストの翻訳**: 選択したテキストをその場で訳す。
- **キャッシュ**: 一度訳したページは再訪問やリロードで訳し直さない。

ショートカット: `Alt+T` 翻訳 / 停止（選択中は選択範囲を翻訳）、`Alt+O` 原文 / 訳文の切り替え

## データの送信と保存

翻訳を実行すると、対象の文章を OpenAI の API（`api.openai.com`）へ送信する。ページ全体の翻訳では画面外の文章も対象になり、翻訳を停止するまで追加・変更された文章も処理する。文脈としてページタイトルの先頭200文字と説明文の先頭300文字も送信する。選択翻訳では選択した文章の先頭8,000文字までを送信する。

ページ本文などに個人情報や機密情報があれば、それも送信対象になり得る。現在はサイト別の翻訳禁止設定や、タイトル・説明文だけを送信しない設定はない。外部へ送信できない情報を含むページでは翻訳を実行しないこと。API には `store: false` を指定しているが、送信先での一切の保持を防ぐ保証ではない。

ページ翻訳の訳文は端末内の拡張用データベースに最大50,000件保存する。訳文は暗号化しておらず、保存期限はない。サインアウトしても訳文は残る。消去するには翻訳中のページで翻訳を停止し、設定画面の「キャッシュを消去」を押す。進行中の処理が後から保存する可能性があるため、サインアウトや手動消去だけで実行中の翻訳が停止するとは限らない。選択翻訳の結果は、この永続キャッシュには保存しない。

認証では `auth.openai.com` と通信し、認証トークンとメールアドレスを端末内に保存する。モデル・言語・表示設定は Chrome の同期用ストレージに保存する。端末やブラウザープロファイルを共有する場合は、これらの保存内容にも注意すること。

## 導入

1. [Releases](https://github.com/shun-shobon/yomi/releases) から最新の `*-chrome.zip` をダウンロードして展開する。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」から展開したフォルダを選ぶ。
4. 拡張のポップアップから「ChatGPT でサインイン」を押し、開いたタブでアクセスを許可する。

更新するときは新しい zip を同じフォルダに展開し直し、`chrome://extensions` で再読み込みする。

### 翻訳の上限

選択文とページ内の1セグメントは8,000文字まで。ページの1要求は25セグメント・合計20,000文字、タイトルは1,024文字、説明文は2,048文字まで。超過は切り捨てずエラーを表示する。翻訳結果は64,000文字、APIの応答全体は2 MiBで受信を中断する。

翻訳接続は1文書4件・拡張全体16件まで。上限時は待機キューに積まず、完了後の再試行を案内する。未送信接続は15秒、翻訳要求は120秒で終了する。設定・使用量・ショートカット画面を開くAPIは、連打を防ぐため全体で1秒に1回に制限する。
